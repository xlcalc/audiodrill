Add `*` before and after the text to set it in bold.


 `This is a \*bold\* move.`



The result looks like this:

This is a *bold* move.

</div><div id="format-italic" hidden>

Add `~` before and after the text to set it in italic.


 `This is \~funny\~.`



The result looks like this:

This is ~funny~.

</div><div id="format-monospace" hidden>

Add ``` before and after the text to set it in monospace.


 `What does \`break the ice\` mean?`



The result looks like this:

What does `break the ice` mean?

</div><div id="format-smallcaps" hidden>

Add `^^` before and after the text to set it in small caps.


 `A sign on the door read \^\^open\^\^.`



The result looks like this:

A sign on the door read ^^open^^.

</div><div id="format-highlight" hidden>

Add `==` before and after the text to set it in small caps.


 `This is an \==urgent\== matter.`



The result looks like this:

This is an ==urgent== matter.

</div><div id="format-headings" hidden>

To create headings of levels 1–6, put one to six number signs `#` at the start of a line, followed by a space and the heading name. Also put blank lines before and after a heading.

`\##### Heading level 5`

`\###### Heading level 6`



The result looks like this:

##### Heading level 5

###### Heading level 6

</div><div id="format-collapsible" hidden>

Add `\{\{\{` after a heading and close the section with `\}\}\}` to create a collapsible block.

<x-copy>`More details \{\{\{`
`This content can be collapsed.`
`\}\}\}`</x-copy>



The result looks like this:

More details {{{
This content can be collapsed.
}}}

</div><div id="format-link" hidden>

Links are wrapped in square brackets followed by the URL in parentheses: `\[text\]\(URL\)`.

<x-copy>`See \[hung vs. hanged\]\(https://m-w.com/grammar/hung-or-hanged\) for details.`</x-copy>



The result looks like this:

See [hung vs. hanged](https://m-w.com/grammar/hung-or-hanged) for details.

</div><div id="format-gap" hidden>

Gaps are wrapped in two square brackets and can be blank: `\[\[answer\]\]` or with a hint: `\[\[answer => hint\]\]`.

<x-copy>`The speed \[\[of\]\] light in vacuum is \[\[constant => con__\]\].`</x-copy>



The result looks like this:

The speed [[of]] light in vacuum is [[constant => con__]].

</div><div id="format-dropdown" hidden>

Use `\[\[option 1|**correct option|option 3\]\]` to create a dropdown list. Mark the correct answer with `**`.

<x-copy>`What have you \[\[do|does|did|**done|doing\]\]?`</x-copy>



The result looks like this:

What have you [[do|does|did|**done|doing]]?

</div><div id="format-speaker" hidden>

Add `<\)\)` before a sentence, so that learners could hear it. Text in brackets is not played.


<x-copy>`<\)\)I'm learning English now. <\)\)I try to practice for 15 minutes (or so) every day.`</x-copy>



The result looks like this:

<))I'm learning English now. <))I try to practice for about 15 minutes every day.



Use `<\)\)[text]` to pronounce only that word or phrase instead of the full sentence. This way you can highlight vocabulary or grammar patterns. By default, audio is generated in the task language. To use a different language or accent, add a language code after the text.


<x-copy>`In French, <\))[café] sounds as <\))[café]\(lang: fr-FR)`</x-copy>



The result looks like this:

In French, <))[café] sounds as <))[café](lang: fr-FR)



With `<\)[text]`, you can hide the text and show only the play button. This is useful, e.g., in listening and spelling tests.


<x-copy>`<\)[theatre]\(lang: en-GB) \[\[theatre\]\] (British spelling)`
`<\)[theater]\(lang: en-US) \[\[theater\]\] (US spelling)`</x-copy>



The result looks like this:

<)[theatre](lang: en-GB) [[theatre]] (British spelling)
<)[theater](lang: en-US) [[theater]] (US spelling)

</div><div id="format-avideo" hidden>

{{audio: https://media-ssl.musicradio.com/LBCNewsUK}}

{{video: https://youtu.be/J8EWSLZ36s0}}

The result looks like this:

{{img: https://www.un.org/en/img/splash/un-logo.png center}}
